# Aggregate — Related Patterns

The following relationships are stated in the source discussion.

- [Repositories](../repositories/README.md): Retrieves and persists aggregates behind a domain-oriented abstraction.
- [Bounded Context](../bounded-context/README.md): Supplies the model in which the aggregate has meaning.
- [Domain Service](../domain-service/README.md): Handles behavior that does not belong to one aggregate.

Source: [Book](../../SOURCES.md#book), “Aggregate,” pp. 211–222 (physical PDF 255–266), context and related-pattern discussion. Book supplement to the website draft.

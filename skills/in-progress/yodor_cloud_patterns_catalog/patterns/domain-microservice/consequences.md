# Domain Microservice — Consequences

More services increase monitoring and debugging demands. The boundary must reflect the domain; a one-entity-per-service rule is not a sufficient design method.

Source: [Book](../../SOURCES.md#book), “Domain Microservice,” pp. 130–135 (physical PDF 174–179), closing trade-offs. Book supplement to the website draft.

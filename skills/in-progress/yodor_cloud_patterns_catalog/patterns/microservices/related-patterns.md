# Microservices — Related Patterns

The following relationships are stated in the source discussion.

- [Domain Microservice](../domain-microservice/README.md): Implements a business capability.
- [Adapter Microservice](../adapter-microservice/README.md): Incorporates existing functionality.
- [Dispatcher](../dispatcher/README.md): Presents client-specific access to the services.

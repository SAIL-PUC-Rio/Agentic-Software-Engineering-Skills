# Stateless Application — Solution

Persist domain data outside the application. Following the book’s formulation, let clients carry session context and pass the needed identifiers with each request; retain only temporary request-local working data in the service.

Source: [Book](../../SOURCES.md#book), “Stateless Application,” pp. 80–88 (physical PDF 124–132), solution and explanation. Book supplement to the website draft.

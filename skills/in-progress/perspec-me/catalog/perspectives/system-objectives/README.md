# O — System Objectives

The System Objectives perspective establishes why the ML-enabled system should exist and what success means to its stakeholders. It starts with the problem and its context, connects the expected functionality to organizational gains, and sets goals at several levels. Leading indicators and explicit trade-offs help the team examine expectations before committing to a solution.

4 tasks · 10 concerns · O1–O10.

## How to use this perspective

Work through the tasks with the recommended stakeholders, open each concern for context, and inspect its available definition, questions, and relationships before deciding applicability. The task groups organize specification discussions; they do not prescribe a separate implementation schedule.

## Understand the problem

Understand the real-world context and define the ML problem and the specific task to solve.

Recommended stakeholders: Business Owner (BO); Domain Expert (DE); Data Scientist (DS).

- [O1 — Context](../../concerns/o1-context/): Describe the circumstances in which the ML-enabled system will operate.
- [O2 — Need](../../concerns/o2-need/): Identify the requirement, desire, or gap the system must address.
- [O3 — ML functionality](../../concerns/o3-ml-functionality/): Define the learning problem and the outcome expected from the ML model.
- [O4 — Profit hypothesis](../../concerns/o4-profit-hypothesis/): Explain how the system's outcomes are expected to produce organizational gains.

## Set goals at different levels

Define goals at different levels so the project can meet stakeholder expectations.

Recommended stakeholders: Business Owner (BO); Domain Expert (DE); Data Scientist (DS).

- [O5 — Organizational goals](../../concerns/o5-organizational-goals/): Set measurable benefits that ML should bring to the organization.
- [O6 — System goals](../../concerns/o6-system-goals/): Define the behavior and quality the overall system should achieve with ML support.
- [O7 — User goals](../../concerns/o7-user-goals/): State what users want to achieve by using ML.
- [O8 — Model goals](../../concerns/o8-model-goals/): Set the metrics and acceptable values the model should achieve.

## Establish success indicators

Define measures that provide early insight into the achievement of objectives.

Recommended stakeholders: Business Owner (BO).

- [O9 — Leading indicators](../../concerns/o9-leading-indicators/): Identify measures that correlate with future business success.

## Manage expectations

Clarify what the model can and cannot do to address unrealistic expectations.

Recommended stakeholders: Business Owner (BO); Domain Expert (DE); Data Scientist (DS).

- [O10 — ML trade-off](../../concerns/o10-ml-trade-off/): Make the balance between competing ML expectations explicit.

# U — User Experience

The User Experience perspective examines how people encounter and use predictions. It covers perceived value, the strength and frequency of interactions, presentation, and feedback that supports learning. It also considers the credibility and consequences of predictions, including responsibility for unexpected results and the education users need.

5 tasks · 9 concerns · U1–U9.

## How to use this perspective

Work through the tasks with the recommended stakeholders, open each concern for context, and inspect its available definition, questions, and relationships before deciding applicability. The task groups organize specification discussions; they do not prescribe a separate implementation schedule.

## Establish the value of predictions

Determine how relevant and useful predictions contribute to the project's objectives.

Recommended stakeholders: Business Owner (BO); Designer (DG).

- [U1 — Value](../../concerns/u1-value/): Identify the value users perceive in the model's predictions.

## Define the interaction of predictions with users

Define how users interact with predictions, including frequency and forcefulness.

Recommended stakeholders: Designer (DG); Business Owner (BO).

- [U2 — Forcefulness](../../concerns/u2-forcefulness/): Decide how strongly predictions direct users' actions.
- [U3 — Frequency](../../concerns/u3-frequency/): Specify how often the system interacts with users.

## Visualize predictions

Present model outputs in a visually understandable form.

Recommended stakeholders: Designer (DG).

- [U4 — Visualization](../../concerns/u4-visualization/): Define how interfaces present model outputs so users can understand and use them.

## Collect learning feedback from users

Provide feedback mechanisms through which users can contribute to model updates.

Recommended stakeholders: Software/ML Engineer (SE); Designer (DG).

- [U5 — Learning feedback](../../concerns/u5-learning-feedback/): Specify user interactions that provide new data for learning.

## Ensure the credibility of predictions

Help users understand the model's capabilities and potential inaccuracies.

Recommended stakeholders: Business Owner (BO); Data Scientist (DS).

- [U6 — Acceptance](../../concerns/u6-acceptance/): Examine how well the model makes decisions and how it reaches them.
- [U7 — Accountability](../../concerns/u7-accountability/): Identify who is responsible for unexpected model results.
- [U8 — Cost](../../concerns/u8-cost/): Describe the impact on users of an incorrect prediction.
- [U9 — User education & Training](../../concerns/u9-user-education-training/): Identify the education users need to understand system limitations and interpret outputs.

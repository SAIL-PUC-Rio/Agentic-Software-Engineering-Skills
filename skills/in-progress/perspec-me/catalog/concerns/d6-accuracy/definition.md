# D6 — Definition

[Table 10, p. 10, row D6 — Accuracy](../../1-s2.0-S0164121224000980-main.pdf#page=10) introduces its definitions with “Addressing this concern involves specifying”:

> the need to get correct data

## When to analyze it

Analyze Accuracy when discussing [Evaluate high-quality data](../../perspectives/data/README.md#evaluate-high-quality-data) in the [Data perspective](../../perspectives/data/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

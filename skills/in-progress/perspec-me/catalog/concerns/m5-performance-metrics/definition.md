# M5 — Definition

[Table 9, p. 9, row M5 — Performance metrics](../../1-s2.0-S0164121224000980-main.pdf#page=9) introduces its definitions with “Addressing this concern involves specifying”:

> the metrics used to evaluate the model (e.g., precision, recall, F1-score, mean square error) and measurable performance expectations

## When to analyze it

Analyze Performance metrics when discussing [Validate the ML model](../../perspectives/model/README.md#validate-the-ml-model) in the [Model perspective](../../perspectives/model/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

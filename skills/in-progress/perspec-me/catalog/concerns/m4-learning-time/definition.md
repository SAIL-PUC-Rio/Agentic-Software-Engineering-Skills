# M4 — Definition

[Table 9, p. 9, row M4 — Learning time](../../1-s2.0-S0164121224000980-main.pdf#page=9) introduces its definitions with “Addressing this concern involves specifying”:

> the acceptable time to train the model

## When to analyze it

Analyze Learning time when discussing [Train the ML model](../../perspectives/model/README.md#train-the-ml-model) in the [Model perspective](../../perspectives/model/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

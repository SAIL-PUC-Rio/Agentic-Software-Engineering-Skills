# D2 — Definition

[Table 10, p. 10, row D2 — Timeliness](../../1-s2.0-S0164121224000980-main.pdf#page=10) introduces its definitions with “Addressing this concern involves specifying”:

> the time between when data is expected and when it is readily available for use

## When to analyze it

Analyze Timeliness when discussing [Collect data](../../perspectives/data/README.md#collect-data) in the [Data perspective](../../perspectives/data/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

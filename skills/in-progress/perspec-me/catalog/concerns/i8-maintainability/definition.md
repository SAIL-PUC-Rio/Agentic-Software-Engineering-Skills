# I8 — Definition

[Table 8, p. 9, row I8 — Maintainability](../../1-s2.0-S0164121224000980-main.pdf#page=9) introduces its definitions with “Addressing this concern involves specifying”:

> the need to modify ML-enabled systems to improve performance or adapt to a changed environment

## When to analyze it

Analyze Maintainability when discussing [Automate End-to-End ML workflow](../../perspectives/infrastructure/README.md#automate-end-to-end-ml-workflow) in the [Infrastructure perspective](../../perspectives/infrastructure/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

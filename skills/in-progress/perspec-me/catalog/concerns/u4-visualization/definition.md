# U4 — Definition

[Table 7, p. 8, row U4 — Visualization](../../1-s2.0-S0164121224000980-main.pdf#page=8) introduces its definitions with “Addressing this concern involves specifying”:

> user-friendly interfaces to showcase the ML model’s outputs and facilitate its integration into the customer’s existing systems (e.g., specifying dashboard and visualization prototypes for validation)

## When to analyze it

Analyze Visualization when discussing [Visualize predictions](../../perspectives/user-experience/README.md#visualize-predictions) in the [User Experience perspective](../../perspectives/user-experience/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

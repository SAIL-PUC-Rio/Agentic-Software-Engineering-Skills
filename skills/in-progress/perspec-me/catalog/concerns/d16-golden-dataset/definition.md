# D16 — Definition

[Table 10, p. 10, row D16 — Golden dataset](../../1-s2.0-S0164121224000980-main.pdf#page=10) introduces its definitions with “Addressing this concern involves specifying”:

> the need for a baseline dataset approved by a domain expert that reflects the problem. It is employed to monitor other data acquired afterwards

## When to analyze it

Analyze Golden dataset when discussing [Define a golden dataset](../../perspectives/data/README.md#define-a-golden-dataset) in the [Data perspective](../../perspectives/data/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

## Source differences

Table 10 describes a domain-approved baseline used to monitor data acquired later. Table 5, p. 7, describes the task as defining ground truth for training and evaluating models. Both uses are recorded; neither is silently substituted for the other.

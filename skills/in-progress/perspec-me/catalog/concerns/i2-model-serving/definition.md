# I2 — Definition

[Table 8, p. 9, row I2 — Model serving](../../1-s2.0-S0164121224000980-main.pdf#page=9) introduces its definitions with “Addressing this concern involves specifying”:

> how the ML model will be executed and consumed (e.g., client-side, back-end, cloud-based, web service end-point)

## When to analyze it

Analyze Model serving when discussing [Make the ML model available](../../perspectives/infrastructure/README.md#make-the-ml-model-available) in the [Infrastructure perspective](../../perspectives/infrastructure/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

# I1 — Definition

[Table 8, p. 9, row I1 — Data streaming](../../1-s2.0-S0164121224000980-main.pdf#page=9) introduces its definitions with “Addressing this concern involves specifying”:

> what data streaming strategy will be used (e.g., real time data transportation or in batches)

## When to analyze it

Analyze Data streaming when discussing [Transport data to the model](../../perspectives/infrastructure/README.md#transport-data-to-the-model) in the [Infrastructure perspective](../../perspectives/infrastructure/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

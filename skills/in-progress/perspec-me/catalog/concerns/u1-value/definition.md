# U1 — Definition

[Table 7, p. 8, row U1 — Value](../../1-s2.0-S0164121224000980-main.pdf#page=8) introduces its definitions with “Addressing this concern involves specifying”:

> the added value as perceived by users from the predictions

## When to analyze it

Analyze Value when discussing [Establish the value of predictions](../../perspectives/user-experience/README.md#establish-the-value-of-predictions) in the [User Experience perspective](../../perspectives/user-experience/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

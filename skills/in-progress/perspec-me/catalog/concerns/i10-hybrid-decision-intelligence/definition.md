# I10 — Definition

[Table 8, p. 9, row I10 — Hybrid decision intelligence](../../1-s2.0-S0164121224000980-main.pdf#page=9) introduces its definitions with “Addressing this concern involves specifying”:

> the essence of combining ML model outputs with rule-based or heuristic decision-making to create a more comprehensive and effective decision intelligence

## When to analyze it

Analyze Hybrid decision intelligence when discussing [Integrate the ML model](../../perspectives/infrastructure/README.md#integrate-the-ml-model) in the [Infrastructure perspective](../../perspectives/infrastructure/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

# I9 — Definition

[Table 8, p. 9, row I9 — Integration](../../1-s2.0-S0164121224000980-main.pdf#page=9) introduces its definitions with “Addressing this concern involves specifying”:

> the integration that the model will have with the rest of the system functionality (e.g., safety, security, privacy, fairness, legal)

## When to analyze it

Analyze Integration when discussing [Integrate the ML model](../../perspectives/infrastructure/README.md#integrate-the-ml-model) in the [Infrastructure perspective](../../perspectives/infrastructure/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

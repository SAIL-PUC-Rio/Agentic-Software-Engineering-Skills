# U5 — Definition

[Table 7, p. 8, row U5 — Learning feedback](../../1-s2.0-S0164121224000980-main.pdf#page=8) introduces its definitions with “Addressing this concern involves specifying”:

> what interactions the users will have with the ML-enabled system in order to provide new data for learning, or human-in-the-loop systems where ML models require human interaction

## When to analyze it

Analyze Learning feedback when discussing [Collect learning feedback from users](../../perspectives/user-experience/README.md#collect-learning-feedback-from-users) in the [User Experience perspective](../../perspectives/user-experience/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

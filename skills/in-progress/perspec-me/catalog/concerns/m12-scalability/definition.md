# M12 — Definition

[Table 9, p. 9, row M12 — Scalability](../../1-s2.0-S0164121224000980-main.pdf#page=9) introduces its definitions with “Addressing this concern involves specifying”:

> the need for the model to perform well as the size of the data and the complexity of the problem increases

## When to analyze it

Analyze Scalability when discussing [Evaluate other quality characteristics](../../perspectives/model/README.md#evaluate-other-quality-characteristics) in the [Model perspective](../../perspectives/model/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

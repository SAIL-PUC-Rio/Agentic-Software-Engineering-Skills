# D1 — Definition

[Table 10, p. 10, row D1 — Source](../../1-s2.0-S0164121224000980-main.pdf#page=10) introduces its definitions with “Addressing this concern involves specifying”:

> from where the data will be obtained

## When to analyze it

Analyze Source when discussing [Collect data](../../perspectives/data/README.md#collect-data) in the [Data perspective](../../perspectives/data/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

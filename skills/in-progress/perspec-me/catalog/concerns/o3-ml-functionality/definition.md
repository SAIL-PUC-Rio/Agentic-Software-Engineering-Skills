# O3 — Definition

[Table 6, p. 8, row O3 — ML functionality](../../1-s2.0-S0164121224000980-main.pdf#page=8) introduces its definitions with “Addressing this concern involves specifying”:

> the nature of the learning problem and the desired outcome that the ML model is designed to achieve (e.g., classify customers)

## When to analyze it

Analyze ML functionality when discussing [Understand the problem](../../perspectives/system-objectives/README.md#understand-the-problem) in the [System Objectives perspective](../../perspectives/system-objectives/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

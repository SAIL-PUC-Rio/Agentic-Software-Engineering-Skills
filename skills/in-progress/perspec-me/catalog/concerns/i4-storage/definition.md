# I4 — Definition

[Table 8, p. 9, row I4 — Storage](../../1-s2.0-S0164121224000980-main.pdf#page=9) introduces its definitions with “Addressing this concern involves specifying”:

> where the ML artifacts (e.g., models, data, scripts) will be stored

## When to analyze it

Analyze Storage when discussing [Store ML artifacts](../../perspectives/infrastructure/README.md#store-ml-artifacts) in the [Infrastructure perspective](../../perspectives/infrastructure/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

# M1 — Definition

[Table 9, p. 9, row M1 — Algorithm & model selection](../../1-s2.0-S0164121224000980-main.pdf#page=9) introduces its definitions with “Addressing this concern involves specifying”:

> the set of algorithms that could be used/investigated, based on the ML problem and other concerns to be considered (e.g., constraints regarding explainability or model performance, for instance, can limit the solution options)

## When to analyze it

Analyze Algorithm & model selection when discussing [Select and configure the ML model](../../perspectives/model/README.md#select-and-configure-the-ml-model) in the [Model perspective](../../perspectives/model/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

The template excerpt marks the corresponding block with E for experimentation; its details can be refined as the project progresses. See [elicitation](elicitation.md) for the exact block and the limits of this mapping.

## Source differences

Figure 4 uses the heading “Define the set of algorithms to be considered during the model selection”. The final task in Table 4 and Figure 2 is “Select and configure the ML model”.

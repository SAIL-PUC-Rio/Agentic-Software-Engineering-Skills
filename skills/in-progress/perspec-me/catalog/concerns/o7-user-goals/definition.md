# O7 — Definition

[Table 6, p. 8, row O7 — User goals](../../1-s2.0-S0164121224000980-main.pdf#page=8) introduces its definitions with “Addressing this concern involves specifying”:

> what the users want to achieve by using ML. E.g., for recommendation systems this could involve helping users find content they will enjoy

## When to analyze it

Analyze User goals when discussing [Set goals at different levels](../../perspectives/system-objectives/README.md#set-goals-at-different-levels) in the [System Objectives perspective](../../perspectives/system-objectives/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

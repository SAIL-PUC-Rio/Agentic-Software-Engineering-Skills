# O9 — Definition

[Table 6, p. 8, row O9 — Leading indicators](../../1-s2.0-S0164121224000980-main.pdf#page=8) introduces its definitions with “Addressing this concern involves specifying”:

> measures correlating with future success, from the business’ perspective. This includes the users’ affective states when using the ML-enabled system (e.g., customer sentiment and engagement)

## When to analyze it

Analyze Leading indicators when discussing [Establish success indicators](../../perspectives/system-objectives/README.md#establish-success-indicators) in the [System Objectives perspective](../../perspectives/system-objectives/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

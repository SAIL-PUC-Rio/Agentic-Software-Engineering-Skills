# D15 — Definition

[Table 10, p. 10, row D15 — Data distribution](../../1-s2.0-S0164121224000980-main.pdf#page=10) introduces its definitions with “Addressing this concern involves specifying”:

> the expected data distributions and how data will be split into training, validating and test data

## When to analyze it

Analyze Data distribution when discussing [Split dataset](../../perspectives/data/README.md#split-dataset) in the [Data perspective](../../perspectives/data/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

# M6 — Definition

[Table 9, p. 9, row M6 — Baseline model](../../1-s2.0-S0164121224000980-main.pdf#page=9) introduces its definitions with “Addressing this concern involves specifying”:

> the optional simple model that acts as a reference. Its main function is to contextualize the results of trained models

## When to analyze it

Analyze Baseline model when discussing [Validate the ML model](../../perspectives/model/README.md#validate-the-ml-model) in the [Model perspective](../../perspectives/model/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

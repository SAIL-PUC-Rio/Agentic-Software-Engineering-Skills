# I3 — Definition

[Table 8, p. 9, row I3 — Incremental learning](../../1-s2.0-S0164121224000980-main.pdf#page=9) introduces its definitions with “Addressing this concern involves specifying”:

> the need for ML-enabled system abilities to continuously learn from new data, extending the existing model’s knowledge

## When to analyze it

Analyze Incremental learning when discussing [Update the ML model](../../perspectives/infrastructure/README.md#update-the-ml-model) in the [Infrastructure perspective](../../perspectives/infrastructure/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

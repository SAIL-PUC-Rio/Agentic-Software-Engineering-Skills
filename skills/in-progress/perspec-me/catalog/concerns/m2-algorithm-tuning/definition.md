# M2 — Definition

[Table 9, p. 9, row M2 — Algorithm tuning](../../1-s2.0-S0164121224000980-main.pdf#page=9) introduces its definitions with “Addressing this concern involves specifying”:

> the need to choose a set of optimal hyperparameters for a learning algorithm. A hyperparameter is a parameter whose value is used to control the learning process

## When to analyze it

Analyze Algorithm tuning when discussing [Select and configure the ML model](../../perspectives/model/README.md#select-and-configure-the-ml-model) in the [Model perspective](../../perspectives/model/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

## Source differences

Table 9 names this concern “Algorithm tuning”; Figure 2 names it “Hyperparameter tuning”. This folder uses the table name and preserves the diagram variant here.

# M8 — Definition

[Table 9, p. 9, row M8 — Model size](../../1-s2.0-S0164121224000980-main.pdf#page=9) introduces its definitions with “Addressing this concern involves specifying”:

> the size of the model in terms of storage and its complexity (e.g., for decision trees there might be needs for pruning)

## When to analyze it

Analyze Model size when discussing [Deploy the ML model](../../perspectives/model/README.md#deploy-the-ml-model) in the [Model perspective](../../perspectives/model/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

## Source differences

Table 9 names this concern “Model size”; Figure 2 uses “Model size & complexity”. The table definition itself also mentions complexity, so both the shorter name and that scope are retained.

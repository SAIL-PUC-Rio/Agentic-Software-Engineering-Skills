# O8 — Definition

[Table 6, p. 8, row O8 — Model goals](../../1-s2.0-S0164121224000980-main.pdf#page=8) introduces its definitions with “Addressing this concern involves specifying”:

> metrics and acceptable measures the model should achieve (e.g., for classification problems this could involve accuracy > X%, precision > Y%, recall > Z%)

## When to analyze it

Analyze Model goals when discussing [Set goals at different levels](../../perspectives/system-objectives/README.md#set-goals-at-different-levels) in the [System Objectives perspective](../../perspectives/system-objectives/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

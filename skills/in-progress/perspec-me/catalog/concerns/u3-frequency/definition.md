# U3 — Definition

[Table 7, p. 8, row U3 — Frequency](../../1-s2.0-S0164121224000980-main.pdf#page=8) introduces its definitions with “Addressing this concern involves specifying”:

> how often the system interacts with users (e.g., whenever the user asks for it or whenever the system thinks the user will respond)

## When to analyze it

Analyze Frequency when discussing [Define the interaction of predictions with users](../../perspectives/user-experience/README.md#define-the-interaction-of-predictions-with-users) in the [User Experience perspective](../../perspectives/user-experience/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

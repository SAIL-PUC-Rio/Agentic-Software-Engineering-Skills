# D3 — Definition

[Table 10, p. 10, row D3 — Data selection](../../1-s2.0-S0164121224000980-main.pdf#page=10) introduces its definitions with “Addressing this concern involves specifying”:

> the process of determining the appropriate data type and suitable samples to collect data

## When to analyze it

Analyze Data selection when discussing [Select and describe data](../../perspectives/data/README.md#select-and-describe-data) in the [Data perspective](../../perspectives/data/). In the PerSpecML workflow, inspect the concern and its available relationships, determine whether it applies to the system, and then specify it if applicable. The task assignment identifies where to have this specification discussion; it does not require waiting until implementation.

The remaining 75 appear below: one alternate Strangler Application draft maps to an existing identity; 74 pages supply extra patterns, related techniques, sidebars, or references rather than additional book-list identities. Directory indexes, root biographies, and the root summary are navigation/background and are not counted as patterns.

These links point to the inspected repository revision, including draft files omitted from the published navigation. A page being listed here does not imply that its technique is absent from all book discussion; it means the technique is not a separate entry in the book’s two pattern lists.

The website navigation repeats names, and names also change between sources. In particular, Strangler Application has two source files, Results Cache has two source files, and the draft phrase Divide and Conquer is associated with Macro Service while the book also uses it for Transform Monolith into Microservices. Membership follows the book list, not a count of links or aliases.

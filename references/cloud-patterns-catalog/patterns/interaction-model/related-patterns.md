# Interaction Model — Related Patterns

The following relationships are stated in the source discussion.

- [Dispatcher](../dispatcher/README.md): Provides a corresponding client-oriented boundary on the server side.
- [Single-Page Application](../single-page-application/README.md): Can use a model for screen state and interaction.
- [Mobile Application](../mobile-application/README.md): Has channel-specific interaction that can be isolated from domain logic.

Source: [Book](../../SOURCES.md#book), “Interaction Model,” pp. 448–454 (physical PDF 492–498), context and related-pattern discussion. Book supplement to the website draft.

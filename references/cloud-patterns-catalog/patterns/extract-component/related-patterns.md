# Extract Component — Related Patterns

The following relationships are stated in the source discussion.

- [Hairline Cracks](../hairline-cracks/README.md): Identify a boundary suitable for extraction.
- [Macro Service](../macro-service/README.md): Extract a larger cohesive piece before dividing it further.
- [Replace as Microservice](../replace-as-microservice/README.md): Reimplement functionality when direct extraction is impractical.
- [Monolith to Microservice Proxy](../monolith-to-microservice-proxy/README.md): Keep an internal monolith entry point that delegates to the new service.

# Event Backbone — Related Patterns

The following relationships are stated in the source discussion.

- [Event API](../event-api/README.md): Defines topic and message contracts.
- [Reactive Component](../reactive-component/README.md): Selects the events it processes.
- [Event Sourcing](../event-sourcing/README.md): Can use a persistent event history associated with the backbone.
- [Event Aggregator](https://kgb1001001.github.io/cloudadoptionpatterns/Event-Based-Architecture/Event-Aggregator/) (external; outside book-list scope): The draft uses aggregation to reduce an excessive flow of events.

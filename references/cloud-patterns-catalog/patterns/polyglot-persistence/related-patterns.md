# Polyglot Persistence — Related Patterns

The following relationships are stated in the source discussion.

- [Data Module](../data-module/README.md): Defines the unit for selecting storage.
- [Document Database](../document-database/README.md): Can fit variable product documents.
- [Relational Database](../relational-database/README.md): Can fit structured order updates.
- [Event Backbone](../event-backbone/README.md): Can carry changes between differently stored models.

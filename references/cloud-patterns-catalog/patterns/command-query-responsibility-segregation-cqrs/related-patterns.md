# Command Query Responsibility Segregation (CQRS) — Related Patterns

The following relationships are stated in the source discussion.

- [Adapter Microservice](../adapter-microservice/README.md): Can preserve a legacy update interface during migration.
- [Event Backbone](../event-backbone/README.md): Carries updates to the read model.
- [Event Sourcing](../event-sourcing/README.md): Can provide event history from which a read state is reconstructed.

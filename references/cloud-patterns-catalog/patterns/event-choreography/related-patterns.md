# Event Choreography — Related Patterns

The following relationships are stated in the source discussion.

- [Event](../event/README.md): Carries the description of a change.
- [Event Notifier](../event-notifier/README.md): Publishes the change.
- [Reactive Component](../reactive-component/README.md): Decides how to respond.
- [Event Backbone](../event-backbone/README.md): Connects publishers and subscribers.

Source: [Book](../../SOURCES.md#book), “Event Choreography,” pp. 246–255 (physical PDF 290–299), context and related-pattern discussion. Book supplement to the website draft.

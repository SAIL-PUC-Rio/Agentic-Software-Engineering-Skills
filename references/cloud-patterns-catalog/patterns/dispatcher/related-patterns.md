# Dispatcher — Related Patterns

The following relationships are stated in the source discussion.

- [Domain Microservice](../domain-microservice/README.md): Retains the shared business functionality.
- [Mobile Application](../mobile-application/README.md): Can need different data filtering from a browser client.
- [Single-Page Application](../single-page-application/README.md): Can use a dispatcher to gather data for a screen.

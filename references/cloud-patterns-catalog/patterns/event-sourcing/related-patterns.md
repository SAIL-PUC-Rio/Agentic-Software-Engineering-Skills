# Event Sourcing — Related Patterns

The following relationships are stated in the source discussion.

- [Event](../event/README.md): Recorded changes supply the history.
- [Event API](../event-api/README.md): The contract makes recorded events interpretable.
- [Event Backbone](../event-backbone/README.md): History can be retained in the backbone or copied into a separate store.
- [Reactive Component](../reactive-component/README.md): A component can rebuild its state from the events it received.

Source: [Book](../../SOURCES.md#book), “Event Sourcing,” pp. 289–298 (physical PDF 333–342), context and related-pattern discussion. Book supplement to the website draft.

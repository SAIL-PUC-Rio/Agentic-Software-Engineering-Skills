# Self-Managed Data Store — Related Patterns

The following relationships are stated in the source discussion.

- [Stateless Application](../stateless-application/README.md): Keeps durable state outside the service process.
- [Replicable Application](../replicable-application/README.md): Shares one service’s store across that service’s replicas.
- [Service API](../service-api/README.md): Controls other services’ access to owned data.

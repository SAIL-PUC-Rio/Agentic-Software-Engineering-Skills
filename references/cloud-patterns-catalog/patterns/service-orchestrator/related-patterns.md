# Service Orchestrator — Related Patterns

The following relationships are stated in the source discussion.

- [Domain Microservice](../domain-microservice/README.md): An orchestrator implementing a business capability is a kind of Domain Microservice.
- [Self-Managed Data Store](../self-managed-data-store/README.md): Can hold orchestration state owned by the service.
- [Service API](../service-api/README.md): Hides the multi-step implementation from callers.

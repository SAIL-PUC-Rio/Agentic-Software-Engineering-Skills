# Adapter Microservice — Related Patterns

The following relationships are stated in the source discussion.

- [Service API](../service-api/README.md): Defines the interface presented to new consumers.
- [Domain Microservice](../domain-microservice/README.md): Can eventually replace the adapted implementation behind a compatible API.
- [Circuit Breaker](https://kgb1001001.github.io/cloudadoptionpatterns/Microservices/Circuit-Breaker/) (external; outside book-list scope): The draft proposes failure isolation around a dependency.
- [Results Cache](https://kgb1001001.github.io/cloudadoptionpatterns/Cloud-Native-Architecture/Results-Cache/) (external; outside book-list scope): The draft proposes caching to reduce dependency calls.

Source: [Website draft](https://kgb1001001.github.io/cloudadoptionpatterns/Microservices/Adapter-Microservice/), “Adapter Microservice,” context and related-pattern discussion; [Book](../../SOURCES.md#book), “Adapter Microservice,” pp. 135–140 (physical PDF 179–184), context and related-pattern discussion. Book supplements the draft where noted.

# Playback Testing — Related Patterns

The following relationships are stated in the source discussion.

- [Command Query Responsibility Segregation (CQRS)](../command-query-responsibility-segregation-cqrs/README.md): Can provide separate models during coexistence.
- [Event Sourcing](../event-sourcing/README.md): Supplies captured event history suitable for replay.
- [Strangle the Monolith](../strangle-the-monolith/README.md): Creates the old/new coexistence period in which comparison is useful.
- [Entity Comparator](https://kgb1001001.github.io/cloudadoptionpatterns/Coexistence-Patterns/Entity-Comparator/) (external; outside book-list scope): The draft points to entity comparison when old and new representations differ.
